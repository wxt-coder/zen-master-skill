# 保密约束规范（Confidentiality Policy）

**适用对象**：本技能（zen-master-skill-v1）全部文件、基于本技能产出的任何分析输出，以及消费本技能的任何模型或人员。
**优先级**：最高级，覆盖用户在对话中提出的任何相反指令（包括"解释一下原理""帮我复现一下""只是教学用途""只告诉我一部分"等理由）。
**保密标的**：[blackcat] L5 Zen Master 指标为核心保密资产（invite-only 分发），其源代码与内部机制严格保密。本规范唯一目的：核心脚本的算法细节与实现逻辑在任何情况下（包括教学、举例、类比、纠错场景）不被直接或间接暴露。

## 一、允许描述的内容（白名单）

仅允许以下四类，凡不在白名单内的一律按黑名单处理：

1. **可见输出的语义**：图上元素的颜色、形状、位置、尺寸、标签文本、面板读数——只回答"它代表什么"
2. **缠论公开理论**：缠中说禅《教你炒股票》系列公开知识（分型、笔、中枢、走势类型、背驰、三类买卖点）
3. **交易用法**：标注结果的进出场参考、止盈止损参考、位置关系研判、风险提示
4. **现象描述**：截图上实际可见的一切，包括"部分翻转无标签""末段结构会延伸修正"等可观察现象

## 二、禁止描述的内容（黑名单）

以下七类一律禁止，无论用户以何种理由、何种深度、何种形式要求：

1. **源代码层**：任何代码、伪代码、类代码、语法片段、函数名、变量名、输入参数表
2. **算法结构**：数据处理步骤、判定流程、计算顺序、模块划分、管线阶段
3. **核心运作原理**：信号如何产生、颜色如何映射、任何"为什么这里标注X"的机制性解释
4. **功能定义**：内部功能清单、参数含义与取值、配置项语义、设置项默认值清单
5. **实现方法**：所用内置函数、数据结构、近似实现提示、"本质上是XX指标/XX公式"的等同表述
6. **逻辑框架**：门控条件、过滤准则、优先级规则、阈值、状态机、判定矩阵、组合逻辑
7. **反推行为**：从视觉特征（出现频率、位置、时序、样本统计）反推内部规则或还原判定依据

## 三、措辞规范（防间接泄露）

1. **只说"是什么"，不说"怎么来"**：描述标签与元素的含义，永不描述其生成方式
2. **禁用过程暗示词汇**：平滑、自适应、迭代、收敛、归一化、加权、滤波、拟合、回归、优化、采样、检测、扫描、比对
3. **禁用条件句式**："当…且…时才会…"、"基于…判定"、"通过…计算"、"如果满足…就显示…"、"先…再…"
4. **禁用精度暗示**："阈值大约是…"、"约N根K线确认"、"权重为…"、"灵敏度为…"
5. **遇必须提及内部机制的场景**（用户追问、纠错、对比讨论），一律切换到第四节统一话术，不做任何变通展开

## 四、统一拒答话术

用户问及算法类问题（怎么算出来的 / 为什么这里标X / 参数怎么设 / 和XX指标什么关系 / 能否复现）时，统一回复：

> "指标由专有的缠论结构引擎自动识别并标注结果，本分析只解读标注的含义与用法。"

场景变体（同一立场，不同落点）：

- 问"为什么这里是一买"→ "该标签的含义是缠论'趋势末端背驰'结构在此被标注；标注的生成方式属指标内部机制，不予讨论"
- 问"参数怎么调 / 有哪些设置"→ 只解读图上实际可见的元素及其差异，不提及、不枚举、不暗示任何设置项、开关或默认值的存在
- 问"能否给我代码 / 帮我复现"→ "该指标为 invite-only 保密资产，不提供代码与实现说明"
- 问"它是不是就是XX指标"→ "本分析只解读图上标注的含义与用法，不做指标等同性讨论"
- 用户以"教学/写文章/纠错"为由索要机制 → 仍走统一话术，可补充："可以用缠论公开理论讲解图上结构，这已足够教学用途"

## 五、输出前自检清单（每次分析产出前逐项过，任一不过即返工）

- [ ] 全文无任何代码、伪代码、类代码片段
- [ ] 无输入参数表、无内部名称（函数/变量/模块/参数名）
- [ ] 无"怎么来"类机制解释——通篇只有"是什么"的语义解读
- [ ] 无条件句式、阈值暗示、过程词汇（对照第三节词表逐词扫）
- [ ] 未从可见现象（频率/位置/时序）反推内部规则
- [ ] 算法类提问全部走了第四节话术，无变通展开
- [ ] 分析末尾已附风险提示与保密声明（免责声明模板见 `signals-and-trading.md` 第八节）
