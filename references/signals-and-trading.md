# 买卖点交易系统与操作参考（Zen Master 可视化信号用法）

基于图上可见信号的**用法层**指引。所有内容解释标注结果的交易含义，不涉及指标内部判定机制。本文件同时是给初级用户讲"拿到信号怎么办"的教学材料。

## 1. 信号总览：四类风格对比

| 信号 | 图上形态 | 风格 | 适合人群 | 风险 |
|---|---|---|---|---|
| 一买/一卖 | 低点下绿标签 / 高点上红标签（#1） | 左侧激进，抓反转 | 有经验者小仓 | 高（逆势接刀） |
| 二买/二卖 | 浅绿/橙红标签（#2） | 右侧确认，胜率优先 | 新手首选 | 中 |
| 三买/三卖 | 蓝/紫标签（#3） | 顺势延续 | 趋势交易者 | 中低（怕假突破） |
| B / S | 轨迹点处绿B/红S | 短线择时 | 短线/择时 | 震荡市仍会翻转 |

核心心法：**结构信号（BP/SP）回答"哪里"，择时信号（B/S）与热力颜色回答"何时"，中枢位置回答"值不值得"。**

## 2. 各类买点交易指引（卖点完全镜像）

### 一买（激进抄底）

- **进场**：绿色"一买#N"标签出现（结构确认后），分批小仓试错
- **止损参考**：一买低点下方——跌破则一买结构失效，无条件离场
- **目标参考**：回到中枢下沿 ZD 附近 → 中枢上沿 ZG；若后续出现二买可加仓
- **确认配合**：深蓝/蓝K线簇 + 底分型 + 面板"一买✅"
- **警示**：一买是左侧交易，胜率最低盈亏比最高，严禁重仓

### 二买（稳健确认）

- **进场**：一买之后出现浅绿"二买#N"标签 = 反转确认
- **止损参考**：二买低点（通常高于一买低点）下方
- **目标参考**：前高/上方中枢 ZG；趋势展开后改用跟踪止盈
- **面板配合**："二买 ✅(待触发)"=一买已现、等待回调结构完成——此时开始准备，标签出现再动手
- **定位**：新手最友好的买点——有确认、止损近、逻辑清晰

### 三买（趋势延续）

- **进场**：价格向上离开中枢（站稳 ZG）后，回踩不回框，出现蓝色"三买#N"
- **止损参考**：跌回中枢框内即失效（以 ZG 为界）
- **目标参考**：中枢高度量度思路——突破幅度可参考框体高度（箱体等高）；或看上一个中枢位置
- **面板配合**："三买 ⏳未消费"=该中枢的三买机会还在等待；"✅#N"=第N号中枢的机会已用过
- **定位**：趋势中继信号，顺势者主战场

### B / S（择时信号）

- **用法**：B/S 是择时信号（并非每次动量翻转都会显示标签），适合作为上述结构买点的**时机确认**或短线进出
- **止损参考**：跟随十字点轨迹——红点在价格下方=多头动态支撑，跌破视为短线离场参考；绿点在价格上方=空头压力
- **注意**：十字点变色但无 B/S 标签 = 该次翻转不作为信号处理

## 3. 位置关系速查表（现价 vs 最新中枢）

| 位置 | 结构含义 | 应对思路 |
|---|---|---|
| 中枢上方，回踩不回框 | 多头强势，三买逻辑区 | 持多/寻找三买与B，跌破ZG减仓 |
| 中枢框内 | 震荡区，多空未决 | 空仓等待或高抛低吸，禁追单 |
| 中枢下方，反抽不回框 | 空头强势，三卖逻辑区 | 持空/寻找三卖和S，站回ZD转谨慎 |
| 收盘上穿 ZG（突破上沿标签） | 向上方向选择 | 观察是否回踩确认（防假突破） |
| 收盘下穿 ZD（跌破下沿标签） | 向下方向选择 | 同上镜像 |

## 4. 止盈止损通则

1. **结构止损优先于百分比止损**：每类信号自带失效位（一买低点/二买低点/三买的ZG线/B的轨迹点）
2. **十字点=移动止损参考线**：趋势单可用轨迹点跟踪，牺牲回撤换取趋势空间
3. **目标看对侧**：从中枢一侧看另一侧（ZD↔ZG），趋势离开后看量度幅度
4. **分批进出**：结构信号适合左侧首批+确认后加仓；止盈同理
5. **信号以收盘为准**：盘中信号可能变化，保守者等收盘确认

## 5. 情景推演框架（给结论时的标准句式）

以最新中枢的 ZG/ZD 为参照系组织结论：

- 若价格**站稳 ZG 之上且回踩不回框** → "突破有效，三买逻辑生效，思路转向多头延续，关注 B 信号与 ZG 支撑"
- 若价格**跌回中枢框内** → "突破失败，回归震荡，等待新方向，框内思路高抛低吸"
- 若价格**跌破 ZD 且反抽不回框** → "中枢向下破坏，三卖逻辑生效，思路转向空头"
- 若价格**在中枢内震荡** → "结构未选向，信号质量下降，控制仓位等待离开"
- 若出现**一买标签** → "趋势末端背驰反转尝试，激进者小仓试错，止损一买低点，稳健者等二买确认"

## 6. 综合分析套路（把信号串成完整故事）

给用户的结论按此顺序组织，形成"结构→位置→信号→动作"四层逻辑：

1. **结构层**：图上有几个中枢？抬升/降低/重叠？→ 判定趋势或盘整
2. **位置层**：现价相对最新中枢在哪（框上/框内/框下）？读出标签上的 ZG/ZD 数值与现价比较
3. **信号层**：最近哪些买卖点/B/S？处于什么阶段（面板✅/⏳状态）？
4. **动作层**：对应的情景推演句式 + 进场/止损/目标参考

## 7. 风险与局限清单（每次分析必附）

1. **结构滞后性**：分型/笔/中枢/买卖点均需后续K线确认，最后一段结构可能延伸或修正；历史标注是确定结论，最右端是未完成结构
2. **信号以收盘为准**：盘中出现的信号可能变化
3. **震荡市噪声**：中枢内反复时各类信号频率升高、质量下降，位置关系优先于标签
4. **级别差异**：低周期信号多而噪，高周期少而稳；建议多周期互验
5. **教育用途声明**：本指标与技能用于缠论教学与结构可视化，所有输出仅为技术分析参考，不构成投资建议；用户需自行承担交易决策与风险
6. **禁止外传**：该指标为核心资产，分析输出中不得讨论、推测其内部机制
